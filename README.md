# TikTok Affiliate Protocol Landing Page

Landing page dengan gaya futuristik dan nuansa bawah tanah untuk program **TikTok Affiliate Protocol**. Dibangun menggunakan React + Vite dan menerapkan tema dark mode ekstrem dengan aksen neon.

## Fitur Utama

- Struktur halaman lengkap: Hero, Friction Shift, Protokol, Bukti, Tawaran, Final CTA.
- Copywriting penuh bahasa Indonesia dengan tone tajam dan agresif.
- Desain responsif dengan tipografi tegas, efek neon, dan nuansa glitch.

## Prasyarat

- Node.js 20 atau yang lebih baru.
- npm 10 atau yang lebih baru.

## Cara Menjalankan

```bash
npm install
npm run dev
```

Buka `http://localhost:5173` di peramban.

## Perintah Tambahan

- `npm run lint` – memeriksa kualitas kode.
- `npm run build` – membangun versi produksi.

## Struktur Folder

- `src/App.jsx` – komponen utama landing page.
- `src/App.css` – gaya khusus untuk tiap section.
- `src/index.css` – gaya global dan konfigurasi font.
- `public/` – aset statis.

## Lisensi

Proyek ini dibuat untuk keperluan kampanye TikTok Affiliate Protocol. Silakan modifikasi sesuai kebutuhan kampanye lu.
